# 서준엄마네 모바일 허브 페이지

전단지 QR코드로 들어오는 서준엄마네 상품 소개 페이지입니다.
구매는 이 페이지에서 하지 않고, 상품·카테고리를 누르면 네이버 스마트스토어로 이동합니다.

> **상품·가격·할인·카테고리는 이제 구글 시트 "서준엄마네 웹사이트"에서 고칩니다.**
> 시트를 고치면 약 5분 뒤 사이트에 반영됩니다. 직원용 상세 안내와 배포·되돌리기 방법은 마지막 단계에서 이 문서에 정리합니다.

## 파일 구성

| 파일 | 역할 | 운영자가 고치나요? |
|---|---|---|
| 구글 시트 | 상품 · 가격 · 할인 · 이미지 · 구매 링크 · 카테고리 | **예. 평소에는 여기만 고칩니다.** |
| `data.js` | 시트 주소, 배너 문구, 검증 현장 사진, 고객센터, 비상용 상품 목록 | 가끔 |
| `js/sheet.js` | 시트를 읽고 잘못된 값을 걸러 내는 코드 | 아니오 |
| `tests/sheet-test.js` | 시트 읽기 시험 (`node tests/sheet-test.js`) | 아니오 |
| `index.html` | 화면 디자인과 동작 | 아니오 |
| `assets/products/` | 상품 사진 (정사각형) | 상품 추가 시 사진만 넣기 |
| `assets/banner/` | 메인 배너 사진 3장 (780×474, 2초마다 교체) | 사진 교체 시 |
| `assets/icons/` | 카테고리 아이콘 6종 (정사각형 PNG) | 아이콘 교체 시 |
| `assets/photos/` | 검증 현장 사진 | 사진 교체 시 |
| `assets/brand/` | 로고 | 아니오 |
| `assets/fonts/` | Pretendard (무료 OFL 라이선스) | 아니오 |
| `qr/` | 인쇄용 QR코드 | 아니오 |

## 상품·가격·링크 바꾸는 법

1. `data.js` 를 메모장이나 VS Code로 엽니다.
2. `products` 목록에서 상품명(`name`), 할인 전 가격(`originalPrice`), 특별가(`price`), 링크(`url`)를 고칩니다. 할인이 없으면 `originalPrice` 줄을 지웁니다.
   검증된 제품은 6개 기준이며 한 달 주기로 교체합니다.
3. 상품 사진을 바꾸려면 `assets/products/` 에 사진을 넣고 `image` 에 파일명을 적습니다.
4. 저장한 뒤 아래 "반영하기" 순서를 따릅니다.
5. 반영 후 휴대폰에서 같은 줄 두 제품의 "특가 구매하기" 버튼 높이가 맞는지 확인합니다. 제품명이 길어져도 버튼은 카드 바닥에 맞춰지도록 만들어져 있습니다.

카테고리 링크는 `categories`, 고객센터는 `contact`, 스토어 메인 주소는 `store` 에 있습니다.
카테고리 아이콘을 바꾸려면 `assets/icons/` 에 넣고 각 카테고리의 `icon` 에 파일 경로를 적습니다. 배너 사진과 문구는 `hero` 에서 바꿉니다.

## 반영하기 (GitHub Pages)

이 폴더는 GitHub 저장소이고, `main` 브랜치에 올라간 내용이 그대로 공개 주소에 반영됩니다.

```bash
cd ~/Desktop/g/seojunmom-web
git add -A
git commit -m "상품 정보 수정"
git push
```

1~2분 뒤 공개 주소를 새로고침하면 바뀐 내용이 보입니다.
Claude Code에게 "서준엄마네 페이지 상품 가격 바꾸고 반영해줘"라고 요청해도 됩니다.

## 주의

- 스마트스토어 주소는 반드시 실제 주소로 바꿔야 합니다. 처음 만들 때 넣은 주소는 예시입니다.
- QR코드는 공개 주소가 바뀌지 않는 한 다시 만들 필요가 없습니다.
- 로고는 브랜드 가이드라인에 따라 흰 배경 위에만 놓습니다. 그림자·테두리를 넣지 않습니다.

## 클릭 기록기 설치 (처음 한 번만)

사이트에서 누른 상품·카테고리를 구글 시트 '클릭 기록' 탭에 쌓고, '클릭 집계' 탭에서 개수를 봅니다.
손님 개인정보는 저장하지 않습니다. 시간, 종류, 이름, 이동한 주소만 저장합니다.

1. 구글 시트 "서준엄마네 웹사이트"를 엽니다.
2. 메뉴에서 **확장 프로그램 > Apps Script** 를 누릅니다. 새 창이 열립니다.
3. 왼쪽 `Code.gs` 안의 내용을 모두 지우고, 이 저장소의 `apps-script/click-log.gs` 내용을 통째로 붙여 넣습니다.
   - 내용 보기: https://raw.githubusercontent.com/rlgus1520-boop/seojunmom/main/apps-script/click-log.gs
4. 위쪽 디스크 모양 **저장** 버튼을 누릅니다.
5. 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
   - 유형 선택(톱니바퀴) 에서 **웹 앱** 을 고릅니다.
   - 설명: `클릭 기록기`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** 를 누릅니다.
6. 권한 확인 창이 뜨면 **액세스 승인 > 내 계정 선택** 을 합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 > (안전하지 않음)으로 이동 > 허용** 을 누릅니다.
   직접 만든 스크립트라서 나오는 정상 경고입니다.
7. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사합니다.
   이 주소를 브라우저에 열어 "서준엄마네 클릭 기록기가 작동 중입니다." 가 나오면 성공입니다.
8. 그 주소를 `data.js` 의 `clickLog: ""` 따옴표 안에 넣고 반영합니다.

스크립트 코드를 고친 뒤에는 **배포 > 배포 관리 > 연필(수정) > 버전: 새 버전 > 배포** 를 해야 반영됩니다.
이렇게 하면 웹 앱 주소가 바뀌지 않습니다. "새 배포"를 다시 하면 주소가 바뀌니 주의하세요.

직원이 시험으로 누른 클릭이 기록되지 않게 하려면 주소 끝에 `?nolog` 를 붙여서 엽니다.
