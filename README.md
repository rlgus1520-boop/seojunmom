# 서준엄마네 모바일 허브 페이지

전단지 QR코드로 들어오는 서준엄마네 상품 소개 페이지입니다.
구매는 이 페이지에서 하지 않고, 상품·카테고리를 누르면 네이버 스마트스토어로 이동합니다.

## 파일 구성

| 파일 | 역할 | 운영자가 고치나요? |
|---|---|---|
| `data.js` | 문구 · 상품 · 가격 · 링크 · 카테고리 · 연락처 | **예. 이 파일만 고치면 됩니다.** |
| `index.html` | 화면 디자인과 동작 | 아니오 |
| `assets/products/` | 상품 사진 (정사각형) | 상품 추가 시 사진만 넣기 |
| `assets/banner/` | 메인 배너 사진 3장 (780×474, 2초마다 교체) | 사진 교체 시 |
| `assets/icons/` | 카테고리 아이콘 6종 (정사각형 PNG) | 아이콘 교체 시 |
| `assets/photos/` | 검증 현장 사진 | 사진 교체 시 |
| `assets/brand/` | 로고 | 아니오 |
| `assets/fonts/` | Pretendard (무료 OFL 라이선스) | 아니오 |
| `qr/` | 인쇄용 QR코드 | 아니오 |

## 상품·가격·링크 바꾸는 법

1. `data.js` 를 메모장이나 VS Code로 엽니다.
2. `products` 목록에서 상품명(`name`), 할인 전 가격(`originalPrice`), 특별가(`price`), 링크(`url`)를 고칩니다. 할인이 없으면 `originalPrice` 줄을 지웁니다.
   검증된 제품은 6개 기준이며 한 달 주기로 교체합니다.
3. 상품 사진을 바꾸려면 `assets/products/` 에 사진을 넣고 `image` 에 파일명을 적습니다.
4. 저장한 뒤 아래 "반영하기" 순서를 따릅니다.
5. 반영 후 휴대폰에서 같은 줄 두 제품의 "특가 구매하기" 버튼 높이가 맞는지 확인합니다. 제품명이 길어져도 버튼은 카드 바닥에 맞춰지도록 만들어져 있습니다.

카테고리 링크는 `categories`, 고객센터는 `contact`, 스토어 메인 주소는 `store` 에 있습니다.
카테고리 아이콘을 바꾸려면 `assets/icons/` 에 넣고 각 카테고리의 `icon` 에 파일 경로를 적습니다. 배너 사진과 문구는 `hero` 에서 바꿉니다.

## 반영하기 (GitHub Pages)

이 폴더는 GitHub 저장소이고, `main` 브랜치에 올라간 내용이 그대로 공개 주소에 반영됩니다.

```bash
cd ~/Desktop/g/seojunmom-web
git add -A
git commit -m "상품 정보 수정"
git push
```

1~2분 뒤 공개 주소를 새로고침하면 바뀐 내용이 보입니다.
Claude Code에게 "서준엄마네 페이지 상품 가격 바꾸고 반영해줘"라고 요청해도 됩니다.

## 주의

- 스마트스토어 주소는 반드시 실제 주소로 바꿔야 합니다. 처음 만들 때 넣은 주소는 예시입니다.
- QR코드는 공개 주소가 바뀌지 않는 한 다시 만들 필요가 없습니다.
- 로고는 브랜드 가이드라인에 따라 흰 배경 위에만 놓습니다. 그림자·테두리를 넣지 않습니다.
